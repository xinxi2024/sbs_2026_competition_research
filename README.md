# 上商竞赛雷达 · 2026 学科竞赛库

本地静态网站，收录学校 2026 学科竞赛名单中的主表 147 项和右栏 38 项，共 185 条可单独搜索、筛选和打开详情的记录。右栏赛项同时保留与主项目的关联。页面无后端，不会自动上传个人资料。

## 打开方式

双击 `index.html` 可直接浏览。若浏览器限制本地页面操作，可在此目录运行：

```powershell
python -m http.server 8000
```

然后打开 http://localhost:8000 。按 `Ctrl+C` 停止服务。

网站分为三个独立页面：首页 `index.html` 是竞赛项目库，`calendar.html` 是最近赛程，`about.html` 是评估口径。顶部导航可在三页之间切换。

## 数据说明

- `competitions-data.js`：竞赛名单、上海赛区条目、个人适配评估与来源链接。
- `calendar-data.js`：已核实的报名截止/比赛节点，以及年度规律参考。
- `calendar-engine.js`：每次打开页面时按本机日期将年度窗口滚动到下一次；首页详情和独立赛程页共用这一逻辑。
- `calendar.js`：独立赛程页面的时间、日程类型、竞赛方向、个人适配度、校内奖励分类和关键词组合筛选。
- `about.html`：个人适配、获奖区间、成长收益、学校资源和资料来源的评估口径说明。
- `AGENTS.md`：项目内容维护、资料核验、隐私边界与版本提交约定。
- 每个项目详情页都有同一套四步“赛项速读图”，按项目标签调整步骤和配色；这是理解示意图，不是主办方官方赛制图。
- 竞赛分类取自用户提供的《附件：2026年上海商学院学科竞赛名单【学生奖励】》；主表147项和右栏38项分别作为可搜索记录，逐字保留来源名称与各自分类。右栏条目的详情会标明关联主项目，以及哪些内容仍需赛区通知核实。按名单统计，B类甲等共6项（主表2+右栏4），B类乙等共58项（主表24+右栏34）；分类菜单显示每类数量，并可选择“B类全部等级”。
- 目前已有74项主表竞赛录入至少一条官方/校方赛程依据或明确标注的往届参考与下一届关注窗口；赛程覆盖不代表完整章程已核完。另有16项补充了扩展赛事资料，其余项目的资格、赛制、提交物等字段继续逐项核实。时间点按项目注明对应届次、赛道差异和不确定性；年度推算不会标成已发布通知。
- 赛程覆盖包括创新创业、职业规划、机器人与人工智能、信息通信、商业策划、设计创作、计算机应用、财税案例等方向。上海地方赛、全国赛及同一赛事的不同赛道分别说明；若来源只支持月份或范围，就不补造具体日、场地或提交要求。
- 奖金表按用户提供图片转录。公开信息网可检索到的2019版标准不同，金额适用性以学校现行办法和申报审核为准。
- 已核对项目注明参考届次；“待逐项核验”表示需要进一步查当届官方章程。
- 获奖区间是主观筛选估算，不是历史统计结果；置信度偏低。

## 版本更新

每次版本改动完成后，按根目录 `AGENTS.md` 的约定检查改动、提交 Git，并推送到已配置的 `origin` 仓库。请勿把原始个人提示词、评定表或其他个人材料加入网站仓库。
